# Reference Remix Studio Workflow

## Product decision

The marketer should not need to know the required owned footage before AI analysis. The workflow is deliberately split into two AI stages.

## Stage 1 — AI Creative Direction

1. Record and save a competitor or market reference video.
2. Select the Ineffable Beauty treatment.
3. AI extracts reference frames and proposes:
   - the transformed master concept
   - a five-part finished-video structure
   - the recommended owned footage for each part
   - fallback footage, B-roll, text animation or minimal pickup options
   - folder search keywords
   - whether VO is required, optional or unnecessary, with reasons
   - provisional VO and on-screen text
   - crop, motion, line, speed, transition and edit instructions
4. The marketer uses this proposal as the footage-search brief.

## Stage 2 — Material Confirmation and Finalization

For each proposed shot, the marketer records one of:

- Not started
- Found
- Substitute footage
- Pickup required
- Unavailable

The marketer adds the actual file or clip description and any constraints. AI then finalizes:

- the exact material used in each scene
- the final VO decision and rationale
- subtitle and VO copy
- visual effects and edit instructions
- genuinely different pain, contrast, process and offer versions
- minimum remaining pickup or design gaps

## Operating principle

AI proposes first. Humans locate and confirm real material. AI finalizes only after those constraints are known.

This workflow does not require a managed footage library or Google Drive Service Account.
